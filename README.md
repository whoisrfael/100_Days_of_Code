
# 100 Dias de Código em Python 🐍

Bem-vindo ao meu repositório dos **100 Dias de Código em Python**! Aqui, vou documentar minha jornada de aprendizado e prática diária em Python. O objetivo é melhorar minhas habilidades de programação, explorar conceitos avançados e construir projetos interessantes.

## Objetivos 🎯
- Aprender e praticar Python diariamente por 100 dias.
- Explorar tópicos como:
  - Fundamentos da linguagem.
  - Estruturas de dados e algoritmos.
  - Programação orientada a objetos (POO).
  - Manipulação de arquivos e bancos de dados.
  - Desenvolvimento web com Flask/Django.
  - Automação, análise de dados e machine learning.
- Construir projetos práticos para consolidar o conhecimento.

## Regras do Desafio 📜
1. Codificar pelo menos **1 hora por dia**.
2. Documentar o progresso diário neste repositório.
3. Compartilhar aprendizados e desafios enfrentados.
4. Manter a consistência e não pular dias!

## Projetos 🚀
Aqui estão alguns dos projetos que planejo desenvolver durante o desafio:
1. **Calculadora de IMC** - Um programa simples para calcular o Índice de Massa Corporal.
2. **Jogo da Forca** - Implementação do clássico jogo de adivinhação.
3. **To-Do List** - Uma aplicação de linha de comando para gerenciar tarefas.
4. **Web Scraper** - Coleta de dados de sites usando `BeautifulSoup` e `requests`.
5. **API com Flask** - Criação de uma API simples para gerenciar dados.
